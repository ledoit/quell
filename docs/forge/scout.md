# Quell — Scout

**Date:** 2026-10-03
**Status:** Signed 2026-10-05. Soft and Hard both ship. Names does not. The app is that cut: one window, OLL patterns or PLL letters, a pattern opens its cases, a case opens that alg.

**Job.** One window. It opens on the OLL pattern grid. OLL / PLL swaps that grid for the perm letters. A pattern opens that pattern’s cases in the same window. The window does not scroll. Nothing else is in the product.

**Surface.** One desktop window, `100dvh`, `overflow: hidden`. Cells shrink to fit. They do not wrap onto another page.

## Steal

- [Obvious icon picker](https://mobbin.com/screens/9ee3d530-b6bb-4385-9910-31aabefb6d40) — the grid is the whole surface. A few words at the top change what the grid contains.
- [GoFundMe categories](https://mobbin.com/screens/b0f236b0-2133-47b2-9b42-a7a74ab7bf36) — one picture, one word, even cells, light page.
- [Adobe Express icon grid](https://mobbin.com/screens/eb0f73f8-6f69-48bf-acdc-a349cfd5bff2) — equal cells, the picture is the hit target.
- [Etsy category → items](https://mobbin.com/flows/4e888877-dcd4-47de-a115-73b05180588b) — the choice replaces the pane with what is inside it.

## Kill

Scroll. A second page. Search, accounts, alg cards, 3D, queues, sidebars, wizards, dark chrome.

PLL, thirteen letters: A Aa Ab; E; F; G Ga–Gd; H; J Ja Jb; N Na Nb; R Ra Rb; T; U Ua Ub; V; Y; Z. A one-case letter still opens the case grid.

Case labels read `OLL 18` and `Ja`. Tapping a case marks it. It does not open a third screen.
