# Quell — Scout

**Date:** 2026-10-03
**Status:** Signed 2026-10-05. Soft and Hard both ship. Names does not. The app is that cut: one window, OLL patterns or PLL letters, a pattern opens its cases, a case opens that alg.

**Job.** One window. It opens on the OLL pattern grid. OLL / PLL swaps that grid for the perm letters. A pattern opens that pattern’s cases in the same window. The window does not scroll. Nothing else is in the product.

**Surface.** One desktop window, `100dvh`, `overflow: hidden`. Cells shrink to fit. They do not wrap onto another page.

## Addendum — 2026-10-11

**Status:** Signed in chat. Same window, same Soft and Hard. This does not replace the grid.

**Job.** Use the SpeedCubeDB 3x3 standard algorithm, in their notation, for each OLL and PLL. Cube rotations are written out of the algorithm, and the case is turned so that angle matches the moves. Every case draws its side stickers. An OLL’s non-yellow colors are drawn from the arrangements that keep that yellow pattern. Quiz is an infinite multiple-choice drill: one case, three algorithms stacked, and the other two are the closest algorithms by shared triggers (sexy, sledge, sune, and the rest).

**Surface.** The same full-window page. Quiz replaces the grid; it is not a second page.

**Job.** Faces sits beside Soft and Hard. Off, an OLL is still yellow against empty. On, the cube is a legal grip: the top color is not stuck on yellow, the side colors follow that grip, and an OLL's top face is the real stickers, including the ones that are not the top color. PLL uses the same grip. The angle still matches the algorithm.

A case opens on its standard algorithm. The other rows are that algorithm from another top-face start, or the left-hand mirror of an algorithm already in the set, when that version solves this case. One of them is the default. The diagram matches the one that is on. Two algorithms are not shown at once.

A quiz tap turns the chosen row red when it is wrong, and the right row green either way.
