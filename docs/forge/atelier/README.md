# Quell atelier

2026-10-05. Soft and Hard are the app. Names is not. Soft is `shapes.html`. Hard is `chart.html`. The menu switches them.

| Vision | File | What you match by |
| --- | --- | --- |
| Shapes | `shapes.html` | The picture. The face fills the cell. The name is a caption. |
| Names | `names.html` | The word. Lightning, Big L, J are the type. The face is a mark beside it. |
| Chart | `chart.html` | A ruled sheet. Picture and name share each cell. Lines run to the edges. |

`#cases` is Lightning. `#pll` is the perm letters.
